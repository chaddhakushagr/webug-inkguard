# User Testing Observations & Feedback

## Testing Protocol (Post Gate G3)
Each external tester is given 4 tasks without assistance:
1. Log in as Creator and run a review on sample S1.
2. Accept a fix and dismiss a finding with a reason.
3. Log in as Reviewer and approve the revised submission.
4. Locate the cited guideline rationale for a raised finding.
